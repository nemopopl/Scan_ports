# Scan_ports

Мини-сканер открытых портов с отчётом

## О проекте ##

**«Мини-сканер»** — это легковесное программное решение,
предназначенное для быстрого анализа сетевой безопасности и мониторинга доступных сервисов.
Инструмент позволяет пользователю сканировать указанный диапазон IP-адресов или доменных имен на предмет открытых портов.
